How to use this tool

  1. Enter the current statement balance, current Street balance and last import date.
  2. Upload the Street > All Transactions CSV export, or skip this and type the unreconciled totals in manually.
  3. Upload the bank statement lines CSV export to auto-fill imported transactions not yet reconciled, or type it in manually.
  4. Review the KPI cards and status badge below, then use Copy summary to paste the result into Slack, HubSpot or an email.
